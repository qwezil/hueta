Весь сайт — этот один файл. Второй файл, Script.lua, — твой скрипт, который лоадится по прямой ссылке, как на GitHub Raw.

Как поменять скрипт:

  1. Открой файл Script.lua (на GitHub — карандашик ✏️, или у себя в редакторе)
  2. Удали всё и вставь свой код, сохрани / закоммить
  3. Vercel сам передеплоит сайт за ~20 секунд — ссылка та же, код уже новый

Надо ещё скриптов? Просто добавь рядом файл, например Other.lua — он сразу будет доступен по адресу /Other.lua. Ничего настраивать не надо.
